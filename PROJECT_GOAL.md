# Цель
Fish Speech — это многоязычная система синтеза речи (TTS) на основе модели Fish Audio S2 Pro (4B параметров). Проект предоставляет инструменты для преобразования текста в натуральную речь с поддержкой 80+ языков, контролем эмоций и просодии через специальные теги, а также возможностью клонирования голоса. Это — **вендоренный клон upstream-репозитория** (fishaudio/fish-speech).

## Критерии готовности
- [ ] Система может инсталлироваться и запускаться локально или через Docker
- [ ] Поддерживаются основные интерфейсы: CLI, WebUI, gRPC-сервер
- [ ] Модель S2 Pro корректно генерирует речь на множестве языков

## Политика ответов
- Водитель сам решает: локальные правки в скриптах, тесты, документация (не upstream-синхро).
- Эскалировать человеку: синхронизация с upstream (merge PR, pull из upstream), деплой в production, удаление данных, смена зависимостей (torch, transformers версии).

## Ограничения
- Лицензия: **Fish Audio Research License** (проприетарная, см. LICENSE); использование требует соблюдения условий.
- Платформа: Linux/MacOS (Docker поддерживает), требует Python >=3.10, PyTorch 2.8.0.
- Привязка: модели на HuggingFace; зависит от upstream-обновлений fishaudio/fish-speech.
- Вендоренный статус: это копия upstream-репо, локальные правки не синхронизируются обратно.
